Política de Privacidad

Ronquillo Te Cuida · Última actualización: 3 de junio de 2026

Esta Política de Privacidad explica cómo la aplicación y la web Ronquillo Te Cuida tratan los datos personales necesarios para gestionar usuarios, clases, reservas, asistencia, cuotas y notificaciones.

Responsable/desarrollador: Álvaro Pavón. Contacto de privacidad: alvaropavonmartinez7@gmail.com.

1. Datos que recopilamos

  • Datos de cuenta: nombre, correo electrónico, rol de usuario y contraseña protegida mediante hash.
  • Datos de perfil opcionales: teléfono, imagen o fotografía si el usuario o administrador los añade.
  • Datos de actividad: clases reservadas, cancelaciones, lista de espera, validación de asistencia, ausencias y penalizaciones.
  • Datos de cuota: estado de mensualidad, fecha de vencimiento y avisos internos relacionados con pagos.
  • Datos técnicos: token de autenticación, identificadores de sesión, registros básicos de errores y seguridad.
  • Notificaciones push: token Expo Push y plataforma del dispositivo (iOS o Android), solo para enviar avisos relacionados con la actividad del gimnasio.

2. Para qué usamos los datos

  • Permitir el inicio de sesión y proteger el acceso a la aplicación.
  • Gestionar reservas, aforos, listas de espera, asistencia y penalizaciones.
  • Comprobar si un cliente tiene la cuota activa antes de permitir reservas.
  • Enviar recordatorios de clase, avisos de promoción desde lista de espera y notificaciones administrativas.
  • Permitir a administradores y profesores gestionar clases y usuarios según sus permisos.
  • Mantener la seguridad, prevenir abuso y resolver incidencias técnicas.

3. Base legal

Tratamos los datos para prestar el servicio solicitado por los usuarios, gestionar la relación con el gimnasio, cumplir obligaciones aplicables y proteger el funcionamiento seguro de la plataforma. Las notificaciones push se envían cuando el usuario concede permiso en su dispositivo.

4. Con quién compartimos datos

No vendemos datos personales. Podemos usar proveedores técnicos necesarios para operar la aplicación, incluyendo alojamiento del servidor, base de datos, servicios de notificaciones push de Expo y plataformas de distribución de apps como Google Play o Apple App Store. Estos proveedores actúan únicamente para prestar el servicio técnico.

5. Pagos

La aplicación puede registrar avisos o confirmaciones administrativas de cuota, pero no almacena datos completos de tarjetas bancarias. Si en el futuro se integra una pasarela de pago externa, esta política se actualizará antes de activar dicha funcionalidad.

6. Conservación de datos

Conservamos los datos mientras la cuenta esté activa o sean necesarios para gestionar clases, reservas, incidencias, seguridad y obligaciones administrativas. El usuario puede solicitar la eliminación de sus datos cuando ya no sean necesarios para el servicio.

7. Seguridad

Aplicamos medidas razonables de seguridad: contraseñas almacenadas con hash, autenticación mediante token, control de permisos por rol, conexiones protegidas y acceso restringido a la administración. Aun así, ningún sistema conectado a Internet puede garantizar riesgo cero.

8. Derechos del usuario

El usuario puede solicitar acceso, rectificación, eliminación, limitación u oposición al tratamiento de sus datos. Para ejercer estos derechos, debe escribir al correo de contacto indicado en esta política identificando su cuenta.

9. Menores

La aplicación no está dirigida a menores sin autorización de su madre, padre o tutor legal. Si se detecta una cuenta creada sin autorización suficiente, se podrá bloquear o eliminar.

10. Cambios en esta política

Podemos actualizar esta Política de Privacidad cuando cambien las funcionalidades, proveedores o requisitos legales. La versión vigente estará siempre disponible en esta URL.
