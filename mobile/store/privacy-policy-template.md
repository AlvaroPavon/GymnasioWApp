# Política de privacidad — GimnasioWapp

Última actualización: 30 de mayo de 2026

GimnasioWapp permite gestionar clases, reservas, asistencia y cuotas de un gimnasio.

## Datos que tratamos

- Datos de cuenta: nombre, email, rol y teléfono si se informa.
- Datos de actividad: reservas, listas de espera, asistencia y penalizaciones.
- Datos de cuota: estado de mensualidad, fecha de vencimiento y reportes de pago.
- Notificaciones: token push del dispositivo para enviar recordatorios y avisos.
- Imagen de perfil si el usuario o administrador la carga.

## Para qué usamos los datos

- Autenticar usuarios.
- Permitir reservas y control de aforo.
- Gestionar cuotas y avisos administrativos.
- Enviar notificaciones relacionadas con clases y reservas.
- Mantener la seguridad y trazabilidad del sistema.

## Base legal

Tratamos los datos para prestar el servicio contratado por el gimnasio y para cumplir obligaciones administrativas aplicables.

## Conservación

Conservamos los datos mientras la cuenta siga activa o mientras sea necesario por motivos legales, contables o de seguridad.

## Compartición de datos

No vendemos datos personales. Podemos usar proveedores técnicos estrictamente necesarios para hosting, base de datos, notificaciones push y operación de la app.

## Derechos del usuario

El usuario puede solicitar acceso, rectificación o eliminación de sus datos contactando con:

`privacidad@tudominio.com`

Reemplazá este email por el contacto real antes de publicar.

## Seguridad

La app usa comunicaciones HTTPS en producción, contraseñas hasheadas y controles de acceso por rol.

## Cambios

Podemos actualizar esta política cuando cambien las funcionalidades o requisitos legales. La versión vigente estará publicada en la URL informada en las tiendas.
